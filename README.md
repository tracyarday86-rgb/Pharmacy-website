# 💊 Pharmacy Website

A modern, user-friendly, and responsive web application designed for a local pharmacy to display services, showcase available health products, and provide essential contact information.

## ✨ Features

- **Product Showcase:** Display available over-the-counter medications and health care products.
- **Store Info & Hours:** Clearly list business hours, physical location, and contact numbers.
- **Prescription & Inquiries:** Easy-to-use contact options for medication inquiries and assistance.
- **Responsive Layout:** Works smoothly across mobile phones, tablets, and desktop screens.

## 🛠️ Built With

- **HTML5** - Page structure
- **CSS3** - Styling and layout design
- **JavaScript** - Interactivity and frontend functionality
